## Quick Reference: Content Formulas

### Universal Hook Formula (All Platforms)
```
[Bold Statement / Surprising Number / Personal Story Opening]
[Do NOT reveal the resolution yet — create a loop]
[Set up the context in 1-2 lines]
```

### Caption Formula by Goal
| Goal | Formula |
|------|---------|
| Comments | Hook + Value/Story + Specific question |
| Saves | Educational hook + Numbered list + "Save this for later" |
| Profile visits | Who you help + What you deliver + Soft CTA to profile |
| Website clicks | Pain point + Value tease + Clear benefit to clicking |
| Story/BTS | Day-in-the-life opening + Honest look + Relatable close |
| Promotional | Problem → Solution → Social Proof → Deadline CTA |

### Platform-Specific Rules
| Platform | Hook Window | Optimal Length | Best Format | Key Signal |
|----------|------------|----------------|-------------|------------|
| Instagram | First line (before "more") | Short-medium | Reel / Carousel | Saves |
| TikTok | First 3 seconds | 30-60s | Short video | Watch time |
| LinkedIn | First 2-3 lines (before expand) | Medium-long | Document / Text | Dwell time |
| Twitter/X | Full first tweet | Short | Thread | Retweets |
| YouTube | First 30 seconds | 8-15 min | Long-form | Watch time |
| Pinterest | Pin title + description | Medium | Vertical image | Saves |

## Social Media Audit Checklist

### Profile
- [ ] Profile photo: professional, clear face, high quality
- [ ] Bio: who you help + what you deliver + reason to follow
- [ ] Link in bio leads to relevant CTA page
- [ ] Pinned post is your best-performing or most representative content
- [ ] Story highlights organized with branded covers

### Content Quality
- [ ] Every post has a scroll-stopping first line/visual
- [ ] Content has a clear single goal (engagement / saves / clicks)
- [ ] CTA is specific, not generic
- [ ] Format is appropriate for the platform (Reel for reach, carousel for saves)
- [ ] Brand voice is consistent across all posts

### Consistency
- [ ] Posting frequency is sustainable long-term
- [ ] Content themes are clear (3-5 pillars)
- [ ] Posting at peak times for your audience
- [ ] Responding to comments within 60 minutes of posting

### Growth
- [ ] Hashtag strategy tested and updated monthly
- [ ] Platform-native features being used
- [ ] Collaboration plan in place
- [ ] Analytics reviewed weekly to double down on winners

### Ads (if running)
- [ ] Conversion tracking set up (Pixel / CAPI)
- [ ] Retargeting audiences created
- [ ] 3-5 creative variants being tested
- [ ] Weekly performance review and budget optimization
