# Hyperframes - Content Framework Intelligence

20+ proven content frameworks for every format. Apply the right frame to create content that engages, converts, and spreads.

## When to Apply

Use when:
- Starting a piece of content and need a structure
- Stuck on how to frame an idea
- Writing LinkedIn posts, threads, or emails
- Scripting videos or podcast episodes
- Creating any type of content that needs a clear narrative arc

## The Master Framework Library

### 1. Hook-Value-CTA (Universal)
```
HOOK: Stop the scroll / grab attention
VALUE: The meat — teach, entertain, or inspire
CTA: One clear next action
```
Best for: All short-form content (posts, emails, ads)

### 2. Problem-Proof-Pivot (Educational)
```
PROBLEM: Name the exact pain your audience feels
PROOF: Data, story, or observation that validates it's real
PIVOT: Your reframe or solution (the insight)
```
Best for: Thought leadership, LinkedIn, Twitter threads

### 3. Observation-Insight-Application (Thought Leadership)
```
OBSERVATION: Something you noticed (specific, not generic)
INSIGHT: What it MEANS (the non-obvious interpretation)
APPLICATION: How the reader can use this
```
Best for: LinkedIn posts, newsletters, essays

### 4. Before-After-Proof-Bridge (Transformation)
```
BEFORE: Where they are now (painfully specific)
AFTER: Where they could be (aspirational but believable)
PROOF: Evidence this transformation is real
BRIDGE: How you get from before to after
```
Best for: Landing pages, sales emails, case studies

### 5. Contrarian-Proof-Reframe (Viral/Engagement)
```
CONTRARIAN: Take the opposite position of conventional wisdom
PROOF: Why the common belief is wrong (evidence)
REFRAME: The better mental model or approach
```
Best for: Twitter/X, LinkedIn, viral content

### 6. Story-Lesson-Application (Storytelling)
```
STORY: A specific moment or experience (present tense for immediacy)
LESSON: The single insight extracted from the story
APPLICATION: What the reader should do with this lesson
```
Best for: Newsletters, LinkedIn, podcast content

### 7. Trend-Implication-Action (Future-Focused)
```
TREND: What's changing in the world/industry
IMPLICATION: What this means for your audience (consequences)
ACTION: What they should do now to prepare or capitalize
```
Best for: Industry newsletters, LinkedIn, thought leadership

### 8. Expert-Challenge-Synthesis (Deep Thinking)
```
EXPERT VIEW: The mainstream expert position
CHALLENGE: The evidence or argument against it
SYNTHESIS: The more nuanced, accurate view
```
Best for: Long-form essays, newsletters, YouTube

### 9. Myth-Busting Framework
```
MYTH: "Everyone believes [common misconception]..."
REALITY: "But here's what's actually true..."
WHY IT MATTERS: "This changes how you should [action]..."
WHAT TO DO: Corrected approach
```
Best for: Educational content, social media, blog posts

### 10. Results Framework (Case Study)
```
SITUATION: Context and starting point (specific metrics)
CHALLENGE: The problem that needed solving
APPROACH: What was done (process, strategy)
RESULTS: Specific, quantified outcomes
LESSON: The transferable insight
```
Best for: Case studies, testimonials, social proof content

## Platform-Specific Frameworks

### LinkedIn Post Framework
```
LINE 1 (Hook): Bold claim / surprising stat / relatable observation
[line break]
LINE 2-3: Context that makes line 1 make sense
[line break]
BODY (3-5 lines): Main value delivery — can be list, story, or insight
[line break]
CLOSE: Takeaway + CTA question that invites comments
```

### Twitter Thread Framework
```
TWEET 1 (Hook): The promise of the thread — what they'll learn
TWEET 2: Context or background
TWEETS 3-9: Main points (one concept per tweet, can include examples)
TWEET 10: Practical takeaway / how to apply
TWEET 11 (Close): Summary + soft CTA (follow/reply/share)
```

### Newsletter Framework (The Weekly Brief)
```
OPENER: One hook — story, stat, or provocative question
MAIN STORY: 300-400 words on the week's key insight
QUICK HITS: 3-5 links or tips (shorter items)
DEEP DIVE: Optional longer read for those who want more
CLOSE: Personal note + what's coming next week
```

### YouTube Video Framework
```
HOOK (0-30s): Bold statement + preview of what they'll learn
CONTEXT (30-90s): Why this matters, who this is for
CONTENT (90% of video): The main teaching — chunked into clear sections
BRIDGE: Transition to conclusion
CTA (last 30s): Subscribe + related video + offer (if applicable)
```

### TikTok/Reels Script Framework
```
SECOND 0-3: Visual hook + text overlay (bold statement)
SECOND 3-15: Setup the problem or context
SECOND 15-45: The value (tips, how-to, story)
SECOND 45-60: CTA or cliffhanger to next video
```

### Sales Email Framework
```
SUBJECT: [Curiosity/Benefit hook]
LINE 1: Reference a specific pain or trigger
LINE 2-3: One-sentence proof (result you got for someone like them)
LINE 4-5: Why you're reaching out now (reason to contact today)
CTA: One small ask (15-min call? Quick question? See case study?)
PS: (Optional) Add a second proof point or time limitation
```

### Landing Page Copy Framework
```
HEADLINE: Core benefit in under 10 words
SUBHEADLINE: Expand with specifics + who it's for
PROOF STRIP: Logos, ratings, or customer count
HOW IT WORKS: 3 steps (simple process)
FEATURES → BENEFITS: For each key feature
TESTIMONIALS: 3 specific, result-focused quotes
FAQ: Top 5 objections answered
FINAL CTA: Repeat the offer + deadline/guarantee
```

## How to Apply a Framework

```
Step 1: Choose the framework that matches your GOAL
  - Want engagement? → Contrarian or Observation-Insight
  - Want to educate? → Myth-Busting or Expert-Challenge
  - Want conversions? → Before-After-Proof or Results
  
Step 2: Fill in the framework with YOUR specific content
  - Replace generic examples with YOUR specific data/story
  
Step 3: Apply the platform-specific format
  - LinkedIn: Short paragraphs, line breaks
  - Twitter: 280 chars/tweet, numbered
  - Email: No headers, conversational
  
Step 4: Add your voice (the framework is the structure, not the personality)
```
